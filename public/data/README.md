# Bilgi Havuzu / Knowledge Pool

Bu klasör GitHub Actions tarafından saatlik olarak otomatik doldurulur.
Her çalıştırmada Supabase veritabanındaki tüm projeler buraya JSON olarak
dışa aktarılır (`.json` ve sıkıştırılmış `.json.gz`).

This folder is auto-populated hourly by the GitHub Actions workflow.
All projects from the Supabase database are exported here as JSON.
